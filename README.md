# terum-memory

Local-first memory and a decision record for individual developers working with
coding agents. Automatic session capture (Claude Code first), distilled into a
searchable knowledge base with first-class decisions and `check_decision`
conflict receipts — all in one SQLite file at `~/.terum/terum.db`. No server,
no accounts.

**Status: pre-release.** Private build toward v0.1 — the public flip is the
launch. The npm name is claimed: [`terum-memory`](https://www.npmjs.com/package/terum-memory).
